# Roadmap por etapas

- [x] Etapa 1: estructura monorepo, ETL en Python, API Node/Express, UI React semántica, listbox de pacientes y profesionales, filtro por profesión y búsqueda por texto.
- [x] Etapa 2: Google Maps (Maps JS en React, geocodificación en el backend Node con caché en disco, marcadores de paciente y profesional, distancia en línea recta).
- [ ] Etapa 3: filtros de distancia mín/máx, movilidad, disponibilidad; alta/edición de datos operativos del profesional.
- [ ] Etapa 4: ranking de sugeridos (distancia + tiempo de viaje con Distance Matrix + movilidad + disponibilidad) y asignación.
- [ ] Etapa 5: exportar asignaciones, pulido de UX, accesibilidad, pruebas.
